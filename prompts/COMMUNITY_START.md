# Attach your CV and start

Paste this into your own **tool-enabled** Codex, Claude Code or other agent.
Attach your CV. Fill what you know; let the agent ask only for missing details.
Passwords, keys and identity documents do not belong in this prompt.

```text
This is my explicit job-seeker request. Use Vietnam Career Agent Kit.
My attached CV is authorized evidence for local preparation.
Clone: [path, or ask me to select it]
Private workspace outside the clone: [path, or ask me to select it]

Required information (reuse anything already confirmed in my CV):
1. Target roles/domain and seniority: [my choices]
2. Cities and countries where remote work is allowed: [my choices]
3. Employment types and exclusions: [my choices; internships yes/no]
4. Start date, notice and work authorization/sponsorship: [facts or unknown]
5. Salary: [negotiable, or amount/currency/monthly-or-annual/gross-or-net]
6. Are CV contacts current? Application mailbox: [my choices]
7. Already-applied jobs: [tracker/list/none/unknown]

Default goal: 100 new best-fit confirmed applications, across successive batches.
I explicitly request a persistent host goal if the host supports one; reuse an
existing goal rather than creating a competing goal. Otherwise keep a private
checkpoint. Never claim unattended work or a scheduler where none exists.

Read docs/COMMUNITY_START.md, docs/job-seeker-policy.md and the onboarding skill.
Diagnose the actual host and tools. Use start-campaign --cv FILE in my selected
private workspace; --target defaults to 100. No extra model API is required.
Extract my PDF/DOCX with a supported host tool and verify against the original;
the CLI starter only records its path/hash. Import checked UTF-8 evidence, then
show source-backed facts/conflicts for confirmation. Do not invent qualifications.

Ask one compact group of material missing facts and continue independent work.
Use my preferences, not the maintainer's. Rank current full JDs as Strong fit or
Plausible fit; exclude stretches unless I explicitly change scope. Do not lower
fit, locations or truthfulness to reach 100. Deduplicate against my actual ledger.

Tailor, render and inspect every final page. If I request CV enrichment or
review before sending, follow docs/CV_ENRICHMENT.md and complete that exact-version
review first. Keep the same campaign goal and continue independent research.
Before external disclosure, establish
current finite authority and respect host/source confirmations. Login, this goal
and a starter file are not blanket authority. Use available permitted browser or
email tools; if absent, prepare packages and return an accurate handoff.
Start with one browser lane; use up to 10 only after independent sessions are
actually verified. Shared mailbox sends remain serialized.

Save an attempt before submitting once, verify the actual matching receipt,
update my private tracker and close the completed owned tab. Never replay an
uncertain send. Continue authorized batches until 100 qualifying confirmations or
a real user step/limit blocks progress. Keep prior reports, failed/uncertain
attempts, interview invitations, rejections and offers separate. An application
success is a verified submission, not a job offer. No 100/hour promise.

When I later request a mailbox review, use permitted read-only email tools and
match exact role/requisition threads, including Spam. Record evidence and next
steps; don't send replies, accept interviews or mark attendance without authority.
```
