The [Slice 1 CI run](https://github.com/DUYTRUYENTHONG/vietnam-career-agent-kit/actions/runs/39554806475) passed all four Linux/Windows and Python 3.11/3.12 combinations, with 41 tests per job and the fictional demo/source/wrapper checks. This extends generic local-CLI verification to that recorded matrix. Do not infer macOS, other Python versions, host login access or native hooks. `doctor` reports local Python/OS/executable presence without logging in, connecting a browser or calling a model. Its compatibility label describes project test scope, not a new certification run.

Slice 2 optional rendering was executed in [Linux CI](https://github.com/DUYTRUYENTHONG/vietnam-career-agent-kit/actions/runs/39557082895) using Python 3.12.15, LibreOffice 24.2.7.2, DejaVu Sans, python-docx 1.2.0, pypdf 6.10.0, pypdfium2 5.14.0 and Pillow 12.3.0. Six optional tests passed; all five emitted pages were separately inspected after removing the inherited title rule. Local Windows verified DOCX structure/native PDFium preview plus unavailable-converter behavior, not full LibreOffice conversion. Windows/macOS DOCX-to-PDF conversion remains Experimental until measured there. Generic manifest logic runs in the ordinary matrix; this does not verify native hooks, legal platform permissions, authenticated human approval or a browser executor. See RELEASE_SLICE2.md.

Official documentation consulted: [Codex skills](https://learn.chatgpt.com/docs/build-skills), [Codex hooks](https://learn.chatgpt.com/docs/hooks), [Claude skills](https://code.claude.com/docs/en/skills), [Claude hooks](https://code.claude.com/docs/en/hooks). Current docs can describe newer runtimes; inspected documentation is not an executed integration test.

Canonical skills are .agents/skills. Claude wrappers point there and are generated by `python scripts/generate_adapters.py`; `--dry-run` previews and `--check` detects drift. Root AGENTS.md/CLAUDE.md are maintainer instructions. Job-seeker policy/startup is separate. No wrapper grants tool permission, changes a global setting, auto-trusts hooks or copies credentials.

The optional hook helper is tested as a standalone JSON process only. Native lifecycle callbacks and arbitrary tool coverage are unverified. Generic controls and shell wrappers can escape coverage. A failed/missing guard never authorizes disclosure. See HOOKS.md.

Without browsing, use manual structured JD import. Without computer use, produce drafts/reports/manual handoff. Without rendering, report Markdown only. Without native hooks, use the explicit local preflight operations; those operations cannot sandbox unrelated host tools. No fallback is described as a missing capability.
