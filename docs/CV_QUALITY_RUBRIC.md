# CV quality rubric

Hard gates precede editorial scoring: current confirmed candidate facts and
contacts, correct vacancy/language, preserved contribution/date scope, no
unresolved statements, independent factual review, valid final rendered bytes
and page review. External action additionally needs current source permission
and exact disclosure authority. An editorial score cannot override a hard gate.

Each dimension uses 0–3, cited statement IDs and a concise rationale. There is no
combined ATS percentage or interview probability. Anchors: 0 = material issue,
1 = substantial improvement needed, 2 = usable with stated limits, 3 = strong
for this vacancy and evidence. Scores are transparent reviewer judgments.

| Dimension | Evidence to inspect |
|---|---|
| Relevance | Selected experience maps to actual role priorities |
| Specificity | Concrete supported actions, scope/method/outcomes where known |
| Coverage | Supported requirements represented; mandatory gaps remain visible |
| Clarity | Clear role grouping, chronology, understandable language |
| Concision | No duplicate bullets, keyword stuffing or adjective-heavy filler |
| Readability | Natural EN/VI, readable one-column layout and final page evidence |

The wording packet reports represented assessed requirement IDs over **all JD
requirements**, including missing/unknown ones in the denominator. A direct or
partial source-backed matrix link can be represented; coverage does not mean
full qualification. It never converts unknowns into eligibility. Editorial
readability before rendering concerns text; rendered layout must still be
reviewed separately on every page.

Release speed comparisons require the same cohort, outputs and hard gates;
measure cold/warm and browser sessions separately. Blind baseline/enhanced
editorial comparison and human review remain pending in the first slice.
