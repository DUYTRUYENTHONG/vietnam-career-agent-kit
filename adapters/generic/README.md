# Generic local-tool adapter

Read AGENTS.md for maintainer work. Read prompts/MASTER_PROMPT.md only for an explicit career request. Execute scripts/kit.py with the user's existing authorized local tool. Parse schema_version/outcome/data/issues; blocked, needs_input, manual_required, failed and submission_unknown stop the affected step. Never interpret an error as permission.

Verified scope: deterministic CLI subprocess tests on the recorded Python/OS. This does not certify native AI reasoning, hooks or browser APIs. A chat website without local tool execution is instruction-only: manually run commands and supply results. Reading the prompt does not create tool execution.

No provider SDK, account or global settings are added. Host approvals and remote-model processing boundaries still apply. See docs/compatibility.md.
