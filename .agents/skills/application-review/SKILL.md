---
name: application-review
description: Independently critique a job application against its JD and candidate sources for factual accuracy, relevance, scope and unanswered fields. Do not treat review as disclosure approval or invent missing evidence.
---

Read ../../../prompts/MASTER_PROMPT.md. Inputs: full JD, source facts, draft package and source map. Review from the evidence rather than an instruction to approve. Use a separate bounded reviewer when available; otherwise label a separate review pass honestly.

Check titles/dates, overlap counting, credentials, language, contribution scope, metric qualifiers, planned versus deployed features and unsupported JD skills. Verify candidate corrections supersede old text. Separate actual contradictions from ordinary self-report or missing optional dates.

Check fit, readable ordering and required screening questions. Missing salary, authorization or start dates must not receive guessed answers. Content review cannot prove rendered layout, current liveness or submission success.

Output blockers, improvements and draft disposition with source locators. Maximum two revision loops unless the user asks for more. Reviewer may write critique only; the coordinator owns facts/tracker/browser. No transmissions, approval records or claim repairs are permitted.
