---
name: supervised-browser
description: Assist one specifically authorized application through supported browser tools only when destination policy and exact disclosure approval permit it. Otherwise prepare a manual handoff; never run unattended mass applications.
---

Read ../../../prompts/MASTER_PROMPT.md, ../../../docs/COMPATIBILITY.md and ../../../docs/HOOKS.md. Inputs: selected job, independently checked hosts/redirects, current policy evidence, chosen supported browser and exact reviewed package.

Begin preparation-only. Do not open account tabs just because tools exist. Never use cookies/password stores, arbitrary debugging ports, stealth or private traffic endpoints. Candidate handles login credentials, MFA and CAPTCHA. Do not assume another framework's browser connection applies here.

Before personal-data fill/upload, show recipient/requisition, URL/redirects, filenames and current hashes, exact answers, consents and storage/visibility consequences. Obtain specific approval; uploads/autosave may disclose before Submit. Run local package and approval checks, then follow the host's confirmation rules. A local record is not platform permission or user authentication.

Use only approved answers and choices; reobserve after navigation/upload/dialog/redirect. Stop on unexpected required questions, new recipients, failed uploads or expired login. Never take assessments or interviews.

Default final submission to the user. Delegated agent submission needs platform permission, exact user scope and required action-time confirmation. If a generic action cannot be safely identified, hand off. Uncertain results stop retries. Output observed versus user-reported evidence and update the coordinator's tracker. No recruiter messages, withdrawal or scheduling without separate instruction.
